# Dataset Notes

This file contains notes about datasets used in AI retrieval experiments.

Typical dataset types tested:

- document collections
- embedding vectors
- media assets
- structured knowledge bases

Focus of the experiments:

Understanding how AI systems retrieve context across multiple datasets during inference.

In many AI pipelines (especially RAG systems), a single user query can trigger multiple reads across different datasets. Storage architecture plays a major role in latency and cost.

These experiments explore how different dataset layouts affect retrieval performance.
